# Módulo de configuración

## Propósito

La ruta `/configuracion` administra catálogos generales mediante pestañas independientes.

## Categorías

Permite crear categorías jerárquicas, editarlas y eliminarlas lógicamente respetando sus relaciones.

## Bancos

Permite consultar, crear, editar y eliminar lógicamente bancos. Cada banco registra nombre completo, nombre corto opcional, país y zona horaria.

Un banco relacionado con una o más tarjetas no puede eliminarse, incluso si la tarjeta ya no estuviera activa. Los bancos eliminados dejan de aparecer como opción para registrar nuevas tarjetas.
