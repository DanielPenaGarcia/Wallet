# Recurring Income

`RecurringIncome` represents a source of money expected to be received periodically.

## Fields

- `id`: unique identifier.
- `title`: user-facing name or title for the income.
- `expectedAmountCents`: expected amount for each payment period, stored as an integer number of cents.
- `source`: where the income comes from. Supported values are `work`, `business`, `support`, `rent`, and `other`.
- `frequency`: how often the money is received. Supported values are `daily`, `weekly`, `semimonthly`, and `monthly`.
- `paymentSchedule`: JSON configuration for the expected payment date according to the frequency.
- `workSchedule`: optional JSON schedule with work days and one or more time blocks per day.
- `isActive`: whether the income is currently active.
- `createdAt`: creation timestamp.
- `updatedAt`: last update timestamp.

## Payment Schedule

The payment schedule describes when the income is expected to be received. It is independent from the work schedule.

- `daily`: no additional payment day is required.
- `weekly`: stores the weekday when payment is expected.
- `semimonthly`: stores the first payment day and the second payment day, which may be `last`.
- `monthly`: stores the monthly payment day, which may be `last`.

## Work Schedule

`workSchedule` only applies when the income source is `work`. It may be empty because a recurring income can exist without an associated schedule.

The schedule is stored by weekday. Each selected weekday can contain one or more time blocks. A day can have a different block set from the rest of the week.

Rules:

- A recurring income can exist without a work schedule.
- Work schedule only applies when it makes sense for the income source.
- Payment frequency and work schedule are independent concepts.
- A work day can have multiple time blocks.
- Time blocks on the same day must not overlap.
- A block start time must be earlier than its end time.
- Deactivating an income keeps the record available without treating it as active.
- The amount represents the expected income per payment period, not the amount generated by each worked day.
